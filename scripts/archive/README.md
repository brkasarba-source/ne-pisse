# Tarihsel aktarım betikleri

Bu yedi apply-package betiği geçmiş katalog sürümlerini oluşturmak için kullanıldı.
Güncel kataloğa tekrar uygulanmamalıdır: eski verileri veya menü eşleşmelerini silebilirler.
Çalışma dizinine göre dosya yazarlar; arşive taşınmaları güvenli bir yeniden uygulama yöntemi değildir.
Yeni tarifler mevcut katalog korunarak, ayrı araştırma kaydı ve testlerle eklenmelidir.
